---

## Featured Projects

* **Multi-Dimensional Urban Diagnosis & Strategic Planning**  
  Multi-scalar spatial diagnostic framework deploying Uber H3 discrete global grid systems, proxy-based modeling, and policy alignment for data-scarce environments.
* **Automated Public Space Scoring for Action Plan Development**  
  End-to-end spatial database engine in PostgreSQL/PostGIS for microdata ingestion, street vector polygonization, and benchmark-driven municipal investment planning in Sahab, Jordan.
* **Localized Spatial Analytics Engine for SDG 11.7.1 Monitoring**  
  Decentralized, containerized Web GIS application (Docker, Streamlit, OSMnx) designed for high-resolution demographic microdata routing and strict data sovereignty.

---

## Tech Stack & Core Competencies

* **Geospatial & Spatial Analytics:** Uber H3 (DGGS), OSMnx, GeoPandas, NetworkX, Rasterio/Xarray, Voronoi Tessellations, Network Analysis, Hazard Assessment.
* **Database & Data Engineering:** PostgreSQL, PostGIS, Advanced SQL (`pgSQL`), Spatial Indexing, ETL Pipelines, KoboToolbox Integration.
* **Web GIS & Containerization:** Streamlit, Folium, PyDeck, Docker, WSL2.
* **Documentation & Web:** MkDocs (Material Theme), HTML5, Custom CSS (Flexbox/Grid), Git/GitHub Actions.
